# CVMAnalytics v0.25.0 — Model Export Builder

## Added

- **Redesigned Model Mapping into a preview-first Model Export Builder.** Rebuilt the company Model Mapping page around an Excel-style preview of the exported `Model` sheet structure.
- **Interactive Row Inspector.** Added a right-side row inspector to view and debug mapped raw CVM source lines.
- **Raw Source Picker.** Added picker controls to map raw lines from CVM financials.
- **Validation Strip & Preset Controls.** Added a visual validation strip, preset saving/loading controls, and a clearer export action.

## Internal

- Added preview metadata support to `src/read_service.py` for mapping flows.
- Extended mapping bridge types and mock data generator.
- Added regression coverage in `tests/test_excel_mapping.py` for mapping, preset saving, and default company mapping settings.
- Cleaned up typecheck blockers to restore a reproducible production build environment.
