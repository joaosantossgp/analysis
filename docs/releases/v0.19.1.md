# CVMAnalytics v0.19.1 — Analyst Excel Model (Refinement)

`v0.19.1` is a small but high-impact follow-up to `v0.19.0`. It removes
the remaining merged cell, makes the conventions block collapse out of
the way by default, populates the Latest Fiscal Year cell from the
period window when the company info dict is missing it, expands the
statement taxonomy considerably, and tightens the checks and
README/Source-block honesty.

## Summary

- **Zero merged cells anywhere.** The merged title range (`B11:AB11`)
  is gone — the title is now a single B11 cell with the title style
  repeated across the row range via `write_blank` (no real merge in the
  XLSX XML). The post-write validator now fails the export if it finds
  any `mergeCells` entry in any sheet.
- **Conventions block (rows 3:9) is now grouped and hidden by default**
  with `outlineLevel = 1`. The analyst-facing surface starts visually at
  the title row; Excel shows an outline `+` to expand the legend on
  demand. Freeze panes are unchanged (`D27`, columns A:C frozen).
- **Expanded analyst taxonomy.** Each statement is now driven by a
  spine list of CVM `CD_CONTA` codes with explicit indent levels:
  - Income Statement: ~25 spine rows + EBITDA & D&A computed
  - Balance Sheet: ~38 spine rows (Assets + Liabilities & Equity)
  - Cash Flow Statement: ~20 spine rows + FCF computed
  - Optional supplementary statements are handled through the same raw-sheet
    audit path when supported.
- **Mapping by identifier, not by row number.** Each spine code
  resolves to its raw-sheet row via (1) exact `CD_CONTA`, then (2)
  `STANDARD_NAME` fallback. Codes that do not resolve render as `-` and
  are surfaced in the new **Unmapped — &lt;stmt&gt;** rows of the Source
  / Data Quality block. Missing lines therefore never become numeric
  zero.
- **Latest fiscal year is populated.** When `company_info["latest_year"]`
  is missing or the em-dash placeholder, the exporter falls back to the
  most recent annual period present in the selected window.
- **Two new checks.**
  - **Cash Flow Tie** — `DFC ending cash − BPA cash` per period, with
    a `SUMPRODUCT` rollup status.
  - **Net Income Tie** — `DRE NI − DFC starting NI` per period, same
    rollup pattern.
  - **Formula Error Scan** — an explicit `OK` row whose truth value is
    asserted by the post-write validator.
- **README is now honest and dynamic.** It lists only the raw sheets
  actually present in the workbook and the checks it claims are actually
  rendered on the Model sheet.

## Known Limitations

- ROIC, EBITDA growth, EBIT growth, Net Income growth, Debt/Equity, and
  Cash Ratio are listed in the spec but not yet added to the KPI block
  — they are good candidates for v0.19.2 if the analyst needs them.
- Per-share rows are still not populated (CVM `3.99` is in the spine
  but most filings do not report it consistently; it falls through to
  the Unmapped — DRE list when absent).
- Period-end dates are still derived inside the exporter from the
  period label; plumbing `DT_FIM_EXERC` through the read service DTOs
  is deferred.
