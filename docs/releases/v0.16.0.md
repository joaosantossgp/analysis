# CVM Analytics v0.16.0

Phase 5C cleans up repository policy around source-only legacy / hosted
surfaces after the accepted Vite-only desktop runtime in `v0.15.0`.

## Desktop Runtime

- No desktop runtime behavior change.
- `CVMAnalytics.exe` launches the static Vite desktop UI.
- `CVMAnalytics.exe --vite` remains an alias of the default Vite UI.
- `CVMAnalytics.exe --legacy` remains unsupported and continues into Vite after
  a short warning.
- No `node.exe`, Next standalone server, or `web_standalone/` is packaged.

## Source-only Surfaces

- `apps/web/` remains in source as a source-only / hosted legacy Next.js app.
  It is not part of the desktop runtime.
- `apps/api/` remains in source as the hosted/development FastAPI surface. It is
  not part of the desktop runtime.
- `railway.toml` remains as hosted API deployment config.

## CI / Docs

- Default CI now focuses on Python core checks and the `apps/desktop-web` Vite
  typecheck/build.
- Legacy `apps/web` lint/build/e2e checks no longer block default desktop CI.
- Legacy Next/API performance guardrails remain available as a manual workflow.
- Project docs now identify `apps/desktop-web` as the only packaged desktop UI.

## Data Safety

- Persistent user data remains under `%USERPROFILE%\Documents\CVMAnalytics`.
- No user database, output, logs, cache, backup, or recovery data is deleted.
- The GitHub Release ZIP root remains flat: `CVMAnalytics.exe` and `_internal/`.
- The updater helper allowlist remains `CVMAnalytics.exe` and `_internal`.
