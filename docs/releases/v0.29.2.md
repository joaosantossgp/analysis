# CVM Analytics v0.29.2

Patch release for product-direction alignment, analyst workspace clarity, desktop dev data-path safety, and ANEEL distribution ingestion resilience.

## Added

- Product direction and development checklist documents for the local-first analyst workflow.
- Company Workspace audit/planning notes, product gap audit, Critical Factors planning notes, and Energy utilities source-driver readiness documentation.
- Source/grain context in SIN and Distribution Energy charts so analysts can see source family, local cache, frequency, entity grain, and period range before interpreting the data.
- Support for ANEEL ZIP-wrapped CSV resources in Distribution ingestion, with regression coverage for continuity actuals.

## Changed

- Reframed product/design documentation around minimalism, auditability, and avoiding redundant UI panels.
- Improved Company Workspace source/method disclosure and Excel Mapping lineage language.
- Renamed the Company subnav entry from Model Mapping to Excel Mapping.
- Updated desktop dev mode so it uses the real pywebview bridge and release data path instead of inheriting mock bridge settings.
- Bumped app version to `0.29.2` in `desktop/__version__.py`.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
- `npm --prefix apps/desktop-web run build`
- `python scripts/data/check_storage_budget.py`
- `python -m py_compile desktop/app.py desktop/bridge.py`
- `pytest tests -q`

## Release Blocker Before Publication

- `python scripts/data/check_managed_ingestion_contracts.py --require-manifests --scan-sqlite-large-tables` failed locally because the configured data root is missing managed manifests for `ccee_plant_generation_hourly`, `distribution_mmgd_projects`, and `fuel_distribution_sector_intake`.
- Do not publish the `v0.29.2` tag until those manifests exist in the release-validation data root or the release policy is explicitly changed.

## Notes

- GitHub Releases remain the authoritative source for release assets.
- User data remains under `%USERPROFILE%\Documents\CVMAnalytics`.
- The Critical Factors Monitor remains intentionally gated behind source-backed driver readiness.
