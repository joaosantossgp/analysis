# Release v0.10.0

## Summary

Phase 3F adds single-company refresh controls to the experimental Vite
runtime while keeping the default desktop runtime unchanged.

## Changes

- Added `CompanyRefreshPanel` to `/empresas/:cdCvm` in `apps/desktop-web`.
- Added typed `companyRefresh` API facade over existing bridge methods:
  `request_refresh({ cd_cvm })` and `get_refresh_status({ cd_cvm })`.
- Added bridge TypeScript types for existing `RefreshStatusDTO` fields.
- Shows real backend status/freshness/progress fields only; no invented
  freshness metrics.
- Polls active company refresh status every 2s and invalidates company
  info/year/KPI/statement/directory queries after terminal status.

## Explicit Non-Changes

- Default `CVMAnalytics.exe` behavior remains Next/Node.
- `CVMAnalytics.exe --vite` remains experimental.
- No Python bridge method signatures changed.
- No DB schema, updater, migration, or broad refresh pipeline changes.
- No deletion of `apps/web`, `apps/api`, `desktop/node_portable`, or
  `web_standalone`.
