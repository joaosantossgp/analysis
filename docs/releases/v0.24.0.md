# CVMAnalytics v0.24.0

## Changed

- **Remove duplicate company detail navigation.** The redundant back/breadcrumb
  navigation block in the company detail view has been removed. `EntityHeader`
  now renders a single, consistent navigation control; `SubNav` receives the
  corrected prop. Eliminates visual duplication and reduces the component's
  rendered size. (#341)

## Documentation

- **README download link and product screenshots.** The project README now
  includes a direct download link for the Windows release artifact and four
  annotated screenshots (company directory, company overview, financial
  statements, key indicators) to give new users a clear preview of the app.
