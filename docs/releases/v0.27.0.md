# CVM Analytics v0.27.0

Repository organization release for the active Vite desktop application.

## Changed

- Reorganized the Python core into domain packages:
  `src/platform`, `src/companies`, `src/financials`, and `src/refresh`.
- Kept the public desktop bridge and API contracts stable while moving internal
  imports to the new package layout.
- Split the pywebview bridge into `desktop/bridge_api` mixins and kept
  `desktop/bridge.py` as the stable `CVMBridge` entry point.
- Split the financial read service into focused query, export, coverage, and
  refresh-selection modules.
- Moved the landing page to `apps/landing`, canonical account imports to
  `data/import`, and SQL migrations to `data/schema/migrations`.
- Treats `data/reports` as generated output and removes committed report
  artifacts.
- Split Vite bridge energy types and mock fixtures into domain files.
