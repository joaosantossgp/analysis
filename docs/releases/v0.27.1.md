# CVM Analytics v0.27.1

Patch release for the company Overview chart workspace in the Vite desktop UI.

## Changed

- Refined the paired Historical market data and Financial indicators panels so
  their controls use a shared compact period selector and consistent toolbar
  structure.
- Removed the non-blocking stale market-cache banner from the chart body and
  moved cache status into the panel header actions.
- Improved toolbar wrapping and fixed compressed segmented controls, including
  Annual/Quarterly and market view buttons.
- Improved market chart defaults, dense marker handling, price-series visual
  hierarchy, legends, SVG containment, and axis label placement.
- Kept advanced chart and per-series options available through progressive
  disclosure instead of permanently exposing dense configuration controls.
- Synced minor desktop-web bridge/mock type drift that was blocking TypeScript
  validation.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
- `npm --prefix apps/desktop-web run build`
- Playwright CLI visual checks against `npm --prefix apps/desktop-web run dev:mock`
  at 1920, 1600, 1366, 1200, 1199, 1000, 920, and 880 px widths.

## Notes

- No Yahoo Finance ingestion, CVM financial calculations, or desktop updater
  contract changes.
- The frontend package does not currently expose a `lint` script.
