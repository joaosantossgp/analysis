# CVM Analytics v0.26.4

Patch release for CCEE hourly plant generation manual imports.

## Fixed

- Fixed manual imports for `GERACAO_HORARIA_USINA` so large hourly files run in a background job instead of blocking the desktop bridge and leaving the UI stuck on `Importing`.
- Updated the Plant Parcels import UI to track background manual imports and report completion, warnings, or errors from the existing source-status polling.
- Added a regression test proving manual plant parcel imports return `started` and finish in the background.

## Changed

- Bumped app version to `0.26.4` in `desktop/__version__.py` and synced the desktop web mock bridge.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
- `npm --prefix apps/desktop-web run build`
- `python -m py_compile desktop/bridge.py`
- `pytest tests/test_bridge_plant_parcel_import.py -q`
- `pytest tests/energy_kpi/test_plant_parcels.py -q`
- Browser smoke test on `http://127.0.0.1:5173/#/indicators`
