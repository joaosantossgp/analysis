# CVM Analytics v0.26.3

Subrelease update for manual CCEE plant parcel imports.

## Added

- Added a manual file import fallback for CCEE plant parcel monthly data and CCEE hourly plant generation data.
- Added drag-and-drop and multi-file selection support for CCEE source files in the Plant Parcels indicator screen.
- Added manual import diagnostics for file name, file type, detected period, size, hash, inserted rows, skipped rows, and import status.

## Changed

- CCEE source status now preserves cached local data when a later automatic refresh fails.
- Hourly CCEE imports now validate the required source columns before ingesting local files.
- Bumped app version to `0.26.3` in `desktop/__version__.py` and synced the desktop web mock bridge.
