# CVM Analytics v0.26.7

Patch release for smoother Plant Parcels manual imports.

## Fixed

- Fixed manual CCEE hourly generation imports staying visually stuck in `Importing` after the background job had already finished.
- Updated Plant Parcels to keep polling based on the backend job state, not only local page state.
- Refreshed source status, catalog, selected detail, and active chart queries automatically when a plant source job finishes.
- Added a compact in-page progress banner with current file, total file count, cached rows, skipped rows, and last update time.

## Changed

- Exposed plant source job progress metadata through the desktop bridge.
- Bumped app version to `0.26.7` in `desktop/__version__.py` and synced the desktop web mock bridge.

## Validation

- `python -m py_compile desktop/bridge.py`
- `pytest tests/test_bridge_plant_parcel_import.py -q`
- `pytest tests/energy_kpi -q`
- `pytest tests -q`
- `npm --prefix apps/desktop-web run typecheck`
- `npm --prefix apps/desktop-web run build`
