# CVM Analytics v0.26.12

Hotfix release for Indicators SQLite lock handling.

## Fixed

- Fixed the remaining first-load Indicators failure when SQLite reported `database is locked` while applying `PRAGMA synchronous = OFF`.
- Serialized first-time energy KPI engine creation so concurrent indicator tabs do not race the same local SQLite startup path.
- Added retries for transient `database is locked` errors across indicator, SIN, and Plant Parcels read endpoints.

## Changed

- Kept the earlier Indicators and Plant Parcels cache behavior from `v0.26.11`.
- Bumped app version to `0.26.12` in `desktop/__version__.py` and synced the desktop web mock bridge.
