# CVM Analytics v0.17.0 Release Notes

CVM Analytics `v0.17.0` is the stable release of the Node-free desktop application.

## Summary of Changes

- **Stable Desktop Runtime:** Employs a Node-free architecture combining a Python core pipeline with a SQLite local database, served via pywebview/WebView2 and a static Vite frontend.
- **No Node/Next process:** Spawns zero Node.exe child processes. The standalone Next.js server has been completely removed from the packaged bundle, reducing memory usage and packaging footprint.
- **User Data Location:** All user data is preserved in `%USERPROFILE%\Documents\CVMAnalytics` (unaffected by app updates).
- **Excel Export Parity:** Supports full company Excel workbook exports and statement-scoped (e.g. DRE, BPA/BPP, DFC) exports written to the user's Documents folder.
- **Diagnostics Mode Hardening:** Enhanced `--diagnose-runtime` to detect headless/non-interactive environments (`--non-interactive` or `--headless` flags), outputting summary and path directly to stdout instead of blocking on a native Windows message box.
- **KPI Cell Formatting Consistency:** Standardized display formatting for ratios (`x`), scaling (`mn`), basis points (`bps`), and null-value handling (`—`) across both Detail and Indicators views.
- **Tabular Numbers Alignment:** Enforced global tabular numbers CSS styling for all monospace elements (`.font-mono`) to guarantee perfect vertical column alignment.
