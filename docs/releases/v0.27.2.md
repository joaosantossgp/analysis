# CVM Analytics v0.27.2

Patch release introducing a reliable, period-aware automatic Model Mapping engine with user override capabilities.

## Changed

- Added `ModelResolver` backend supporting Jaccard description scoring, positive/negative aliases registry, and manual overrides database storage.
- Fixed a signature mismatch regression in the backend `validate_excel_model_mapping` service method, enabling correct period-level validations.
- Updated the pywebview bridge API and TypeScript types to expose override save/delete actions and resolutions.
- Upgraded the Model Mapping page UI with a Sidebar panel displaying period-aware matching evidence, confidence scores, status badges, and interactive override/clear selectors.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
- `pytest`

## Notes

- Backward-compatible SQLite migration and preset loading are fully preserved.
