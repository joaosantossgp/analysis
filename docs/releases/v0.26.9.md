# CVM Analytics v0.26.9

Patch release for duplicate Plant Parcels manual imports.

## Fixed

- Fixed CCEE hourly generation imports spending minutes reprocessing files that had already been imported successfully.
- Added file-hash deduplication for manual Plant Parcels imports: matching successful imports now reuse cached metadata and skip the expensive parse/upsert path.
- Kept selected-period validation strict, so a duplicate file is skipped only when the requested period matches the period already imported.

## Changed

- Bumped app version to `0.26.9` in `desktop/__version__.py` and synced the desktop web mock bridge.
