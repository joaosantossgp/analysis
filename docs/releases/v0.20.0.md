# CVMAnalytics v0.20.0 - First-Run Company Universe Setup

`v0.20.0` adds a first-run onboarding flow to help new desktop users choose
how much B3 company data to download before entering the main workspace.

## Summary

- Added a first-run setup gate before the desktop dashboard when no setup state
  exists and the local database is empty.
- Added four company-universe presets:
  - Top 100 B3 companies
  - Top 200 B3 companies (recommended default)
  - Top 500 B3 companies
  - All B3 listed companies
- Added loading, progress, success, error, retry, and configure-later states.
- Added persistent setup state so existing users and completed setups are not
  forced through onboarding again.
- Added a `company_universe` table to persist the selected local universe.
- Added an explicit market-cap ranking provider chain:
  1. brapi quote-list provider
  2. local versioned CSV snapshot fallback
  3. opt-in yfinance fallback for personal/dev use
  4. manual all-companies fallback through the CVM company catalog

## Data Source Strategy

CVM remains the primary source for regulatory filings and financial statement
data. Market-cap data is used only to choose the initial company universe.

The primary ranking source is brapi's quote-list endpoint sorted by
`market_cap_basic`. If brapi is not configured or unavailable, the app tries a
local snapshot at `data/metadata/b3_market_cap_universe_snapshot.csv` (or the
path configured by `CVM_COMPANY_UNIVERSE_SNAPSHOT_PATH`). The yfinance provider
is disabled by default and must be explicitly enabled with
`CVM_ENABLE_YFINANCE_UNIVERSE_PROVIDER=true`.

## Known Limitations

- The repository does not yet include a committed market-cap snapshot. Top N
  presets require a brapi token unless a local snapshot is added.
- yfinance remains experimental and opt-in only.
- The setup screen is wired for desktop runtime; browser preview intentionally
  uses a non-destructive fallback state.
