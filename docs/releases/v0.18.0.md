# CVMAnalytics v0.18.0 — Terminal UI Release

CVMAnalytics `v0.18.0` introduces the first full Terminal UI pass for the
desktop app.

## Summary

- Adds terminal-grade navigation, command palette, research workspace layout,
  financial data grids, and export workflow polish.
- Preserves the local-first desktop architecture and existing CVM data paths.
- Keeps the packaged runtime on Vite + pywebview/WebView2 with no Node/Next
  desktop runtime.

## Highlights

- New terminal shell and navigation language for the packaged desktop UI.
- Command palette with keyboard access and company navigation.
- Redesigned company detail page as a dense research workspace.
- Standardized financial statement and KPI grids with sticky headers, compact
  financial rows, period headers, null-safe cells, and monospaced numeric
  alignment.
- Terminal-style export/report workflow showing scope, destination, status,
  result file, and local output behavior.
- Improved shared primitives for panels, state banners, identifiers, metric
  tapes, numeric cells, delta badges, and compact data display.

## Validation

- Frontend typecheck passed.
- Frontend build passed.
- Python tests passed.
- pywebview smoke passed.
- Direct bridge export check passed.

## Architecture Notes

- No Node/Next runtime was reintroduced.
- No persistent user data paths changed.
- Existing local output folder behavior is preserved.
- The packaged ZIP root remains updater-compatible: `CVMAnalytics.exe` and
  `_internal/`.

## Known Limitations

- Browser preview cannot fully render real bridge data without pywebview.
- Manual desktop visual inspection should still be done before marking the
  release final.
