# CVM Analytics v0.26.5

Patch release for CCEE hourly plant generation import performance.

## Fixed

- Fixed manual imports for `GERACAO_HORARIA_USINA` that could appear infinite on large hourly files because parsing was row-by-row.
- Reworked the CCEE hourly parser to use vectorized normalization for reference month, datetime, plant parcel code, text fields, and numeric source columns.
- Batched hourly upserts so large imports do not build one oversized database payload.
- Made CSV reads try the common semicolon-delimited fast parser before falling back to delimiter autodetection.

## Changed

- Bumped app version to `0.26.5` in `desktop/__version__.py` and synced the desktop web mock bridge.

## Validation

- `python -m py_compile src/energy_kpi/plant_parcel_ingest.py`
- `pytest tests/energy_kpi/test_plant_parcels.py -q`
- `pytest tests/test_bridge_plant_parcel_import.py -q`
- `pytest tests/energy_kpi -q`
- Local performance check: 50k synthetic hourly rows parsed in ~1.1s and parsed+upserted in ~3.1s.
