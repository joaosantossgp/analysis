Patch release for the Coverage workspace and release-readiness fixes after `v0.29.0`.

## Added

- Mock bridge implementations for Coverage flows, keeping browser/dev mode aligned with the packaged desktop bridge contract.
- Updated Coverage module screenshots for the current dashboard, prioritization, work queue, capacity, and universe summary views.

- Expanded the Coverage workspace with the P0/P1 best-practice gaps implemented after `v0.29.0`.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
