# Release v0.14.0

## Summary

Phase 4 switches the default desktop UI from Next.js / Node to the static Vite
SPA. The previous Next / Node runtime remains packaged and is reachable via
`CVMAnalytics.exe --legacy`. No legacy code was deleted.

## Changes

- `desktop/app.py::main()` now defaults to the Vite static SPA over a loopback
  HTTP server. `node.exe` is no longer spawned at startup.
- Added `--legacy` CLI flag. `CVMAnalytics.exe --legacy` spawns the bundled
  `node.exe`, launches the Next.js standalone server, and loads the legacy UI.
  Behavior is identical to releases up to and including `v0.13.0`.
- `--vite` kept as an explicit alias of the default so existing shortcuts and
  docs continue to work.
- Window title shows `CVM Analytics (Legacy)` only when `--legacy` is active.
  Default and `--vite` use the plain `CVM Analytics` title.
- `desktop/bridge.py::_runtime_mode()` now reports `vite` for default startup
  and `legacy` for `--legacy`. The Vite `/status` page surfaces the new label
  (`vite (default)` vs `legacy (Next/Node)`) and a fallback hint pointing at
  `CVMAnalytics.exe --legacy`.

## Release Notes

- `CVMAnalytics.exe` now opens the Vite UI by default. No `node.exe` process
  is spawned.
- `CVMAnalytics.exe --legacy` opens the previous Next / Node UI from the same
  bundle.
- `CVMAnalytics.exe --vite` still works as an alias of the default Vite mode.
- No user data location changed. Persistent data remains under
  `%USERPROFILE%\Documents\CVMAnalytics`.
- The updater allowlist / denylist, MOTW strip, .NET / WebView2 preflight,
  and flat-root ZIP layout are unchanged from `v0.13.0`.
- No legacy code was removed. `apps/web/`, `apps/api/`, `desktop/node_portable/`,
  the `web_standalone` data entry in `desktop/app.spec`, and FastAPI
  dependencies remain packaged so `--legacy` continues to work.
- This is a default-switch release. If you hit a Vite-only regression, please
  open an issue and fall back to `--legacy` until it is fixed.

  - `.\dist\CVMAnalytics\CVMAnalytics.exe --diagnose-runtime` — writes log,
