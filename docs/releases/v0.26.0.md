# CVMAnalytics v0.26.0 - Energy Plant Parcel Indicators

## Added

- Added a local-first Energy Utilities plant and plant-parcel data layer in `energy_kpis.db`.
- Added ANEEL SIGA plant registry caching with CEG, regulatory capacity, UF, phase, and source metadata.
- Added CCEE plant parcel monthly caching for `PARCELA_USINA_MONTANTE_MENSAL`.
- Added CCEE hourly plant generation caching for `GERACAO_HORARIA_USINA`, refreshed by selected month only.
- Added plant/parcel source status, refresh log metadata, local row counts, latest reference period, and explicit refresh controls.
- Added the `/indicators` Plant Parcels explorer with source cards, search/filter catalog, and one selected entity detail panel.

## Metrics

- Supports source-backed capacity, authorized capacity, inspected capacity, physical guarantee, generation at center of gravity, verified ONS generation, availability, and unavailability where source rows provide them.
- Adds derived MWh/GWh/TWh/MWmed conversion utilities and capacity factor calculation with leap-year month handling.
- Marks metrics as raw or derived and exposes source, dataset, reference period, local refresh timestamp, unit, and methodology.

## Caveats

- CCEE plant parcels are not assumed to map 1:1 to ANEEL CEG plants or ONS plant/group records.
- CEG may map to multiple CCEE plant parcels.
- ONS plant/group complementary datasets are not part of this release.
- Load and demand remain SIN/system context indicators, not plant-parcel indicators.
- Energia firme, energia assegurada, and gross/net generation are not inferred without an explicit source methodology.
