# Release v0.11.0

## Summary

Phase 3G adds a Vite app status / updater check / diagnostics screen while
keeping the default desktop runtime unchanged.

## Changes

- Added Vite route `/status` with runtime, local data, database, updater,
  recent logs, and diagnostics cards.
- Added typed `appStatus` API facade and bridge contracts.
- Added narrow Python bridge methods:
  - `get_app_status`
  - `open_status_path`
- Added non-destructive GitHub latest-release status through
  `UpdateChecker.get_latest_release_status`.
- Extended database diagnostics with latest report year/period and refresh
  error count.

## Release Notes

- `CVMAnalytics.exe` still starts the Next/Node UI by default.
- `CVMAnalytics.exe --vite` still starts the experimental Vite UI with no
  Node process.
- The new Vite `/status` screen shows app version, runtime mode, bridge state,
  local data paths, SQLite counts, GitHub release check state, compact logs,
  and runtime diagnostics.
- Software update application is intentionally not exposed from Vite in this
  release; the screen checks and links to the GitHub Release only.
- No legacy code was removed.
- Persistent user data remains under
  `%USERPROFILE%\Documents\CVMAnalytics`.
- This is not the final Vite-default release.
