# CVM Analytics v0.26.11

Patch release for Indicators startup reliability and smoother local reads.

## Fixed

- Fixed the first Indicators load occasionally failing with `database is locked` while initializing the energy KPI SQLite database.
- Made energy KPI SQLite startup tolerate a locked WAL setup without blocking read-only catalog access.

## Changed

- Added bridge payload caches for the indicator catalog and country KPI series when the local energy KPI database has not changed.
- Let the Indicators Explorer render the catalog before large cached series and status reads finish loading.
- Kept previous Plant Parcels table/chart data visible while filtered, paged, or chart queries refresh.
- Limited the Plant Parcels source-status read to CCEE sources when the UI is in the CCEE-only Plant Parcels tab.
- Bumped app version to `0.26.11` in `desktop/__version__.py` and synced the desktop web mock bridge.
