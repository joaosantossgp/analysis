# CVM Analytics v0.26.6

Patch release for Plant Parcels loading during large CCEE hourly imports.

## Fixed

- Fixed the Plant Parcels tab showing `database is locked` while a large `GERACAO_HORARIA_USINA` import is writing to SQLite.
- Made Plant Parcels status, catalog, detail, and chart queries use read-only connections instead of opening write transactions.
- Kept Plant Parcels source cards available from built-in metadata even before `energy_sources` has been seeded in the local database.

## Changed

- Bumped app version to `0.26.6` in `desktop/__version__.py` and synced the desktop web mock bridge.
