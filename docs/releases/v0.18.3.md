# CVMAnalytics v0.18.3 — Excel Export Print & Filter Polish

CVMAnalytics `v0.18.3` is a small follow-up to the `v0.18.2` analyst
Excel export, adding two quality-of-life touches that make the workbook
easier to print and to filter. No backend, schema, runtime, or bridge
changes.

## Summary

- **Print setup on the `Financial Statement Model` sheet:**
  - Landscape orientation, A4 paper.
  - Fit to one page wide (height unrestricted).
  - Convention legend / title / company info / period header rows
    (rows 1–21) repeat on every printed page.
  - Narrow margins (0.4 in left/right, 0.5 in top/bottom).
  - Header shows the sheet name and company name; footer shows
    `CVMAnalytics` / `Page N of M` / export date.
  - Explicit print area covering the populated grid.
- **Auto-filter on legacy statement sheets:**
  - `DRE`, `BPA`, `BPP`, `DFC`, `DVA` headers now ship with auto-filter
    enabled (header row only). Analysts can filter `CD_CONTA`,
    `DS_CONTA`, `STANDARD_NAME`, and `LINE_ID_BASE` directly in Excel
    without manually enabling filters.

## Known Limitations

- Auto-filter is not added to the analyst model sheet itself, since
  that sheet uses indented label cells (column B) and section blocks
  that don't behave well under Excel's row-filter model.
- LTM column, common-size percentages, and inline mini-charts remain
  out of scope for this patch — candidates for v0.19.0.
