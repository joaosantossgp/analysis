# CVM Analytics v0.15.0

Phase 5B removes the legacy Next/Node runtime from the packaged desktop app.

## Runtime

- `CVMAnalytics.exe` launches the Vite desktop UI.
- `CVMAnalytics.exe --vite` remains an alias of the default Vite UI.
- `CVMAnalytics.exe --legacy` is no longer supported. It shows a short warning
  and continues into the Vite UI.
- No `node.exe` process is expected in the packaged desktop app.

## Packaging

- Removed `_internal/node.exe`.
- Removed `_internal/web_standalone/`.
- Removed `desktop/node_portable/`.
- Removed the Next standalone build/copy steps from the desktop build.
- Kept `_internal/desktop-web/`, `_internal/update_helper.ps1`,
  `_internal/data/import/gics_mapping.csv`, and pythonnet runtime files.

## Data Safety

- Persistent user data remains under `%USERPROFILE%\Documents\CVMAnalytics`.
- No user database, output, logs, cache, backup, or recovery data is deleted.
- The GitHub Release ZIP root remains flat: `CVMAnalytics.exe` and `_internal/`.
- The updater helper allowlist remains `CVMAnalytics.exe` and `_internal`.

## Source Tree Status

- `apps/web/` remains in source as a source-only legacy / hosted Next.js app. It
  is not part of the desktop runtime.
- `apps/api/` remains in source for the hosted Railway FastAPI and API tests. It
  is not part of the desktop runtime.

Report any regression immediately, especially old shortcuts that still pass
`--legacy`, startup issues, WebView2 rendering problems, update application
failures, or missing data in the Vite screens.
