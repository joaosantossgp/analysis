# CVM Analytics v0.26.10

Patch release for Indicators source cleanup and app loading performance.

## Fixed

- Removed ANEEL as a visible source from Indicators > Plant Parcels, keeping the tab focused on CCEE plant parcel and hourly generation sources.
- Filtered Plant Parcels catalog, status cards, progress banners, detail metrics, and source caveats to the CCEE source set.

## Changed

- Added fast cached bridge paths for Home and Update Base status reads, including refresh status, base health, data coverage, and SIN KPI dashboard.
- Added persistent cache support for database-backed base health and sector directory reads.
- Reduced initial desktop UI bundle work by lazy-loading the command bar, onboarding flow, and heavy Indicators panels.
- Changed sector directory reads so quick lists can skip expensive snapshot calculations and load details only when needed.
- Bumped app version to `0.26.10` in `desktop/__version__.py` and synced the desktop web mock bridge.

## Validation

- `python -m py_compile desktop/bridge.py desktop/services.py src/read_service.py src/query_layer.py apps/api/app/routes/sectors.py`
- `npm --prefix apps/desktop-web run build`

- `pytest apps/api/tests -q`
