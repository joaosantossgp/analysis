# Release v0.14.1 (hotfix)

## Summary

`v0.14.1` is a hotfix on top of the Phase 4 default-Vite release. It fixes
the Vite sectors directory and the company directory sector filter for
user databases that were seeded with CVM/B3 sector labels but no GICS
classification. Vite remains the default UI; `--legacy` still launches
the Next/Node fallback.

## Bug

`v0.14.0`: opening the Vite `/setores` route showed only
`Sem classificacao GICS` with 109 companies, and the company directory
sector filter returned nothing.

Root cause: `companies.gics_sector` / `gics_sub_industry` were never
populated in user databases provisioned by the data pipeline. The Vite
sectors screen and the directory filter only render the 11 official
GICS hubs (`src/gics_manual_mapping.py::GICS_11_SECTORS`); without a
GICS value, every company is treated as unclassified.

## Fix

- `desktop/app.spec` ships `data/import/gics_mapping.csv` into the
  bundle as `_internal/data/import/gics_mapping.csv`.
- `desktop/app.py::_ensure_gics_backfilled` runs on every packaged
  startup (after `_ensure_db_initialized`, before
  `_preflight_pywebview_backend`). It reads the CSV, restricts to
  mapping rows whose `gics_sector` matches one of the 11 canonical
  GICS labels, and UPDATEs only rows where `gics_sector` is NULL or
  empty. Never overwrites a populated GICS row, never touches
  financial data, never modifies `setor_cvm` / `setor_analitico`.
  Logs the outcome to `Documents/CVMAnalytics/recovery.log`.
- `apps/desktop-web/src/routes/SectorsPage.tsx` empty-state now
  describes the GICS-coverage condition and points the user at the
  hotfix and at `scripts/backfill_company_gics.py` /
  `scripts/import_company_gics.py` for self-recovery.

## Release Notes

- `v0.14.1` is a hotfix release. Vite is still the default UI; the
  Next / Node UI is still available via `CVMAnalytics.exe --legacy`.
- No user financial data is deleted or modified by this hotfix.
- Persistent user data remains under
  `%USERPROFILE%\Documents\CVMAnalytics`.
- No legacy code was removed. `apps/web/`, `apps/api/`,
  `desktop/node_portable/`, the `web_standalone` data entry in
  `desktop/app.spec`, and FastAPI dependencies all remain in place.
- The updater allowlist / denylist, MOTW strip, .NET / WebView2
  preflight, and flat-root ZIP layout are unchanged from `v0.14.0`.

- `npm --prefix apps/desktop-web run build` — pass.
- Packaged smoke: launched `dist/CVMAnalytics/CVMAnalytics.exe` against
  a DB with `gics_sector=NULL` for all 109 companies. After launch the
  DB carried 11 GICS hubs (Energy=3, Materials=8, Industrials=12,
  Consumer Discretionary=17, Consumer Staples=9, Health Care=6,
  Financials=20, Information Technology=3, Communication Services=6,
  Utilities=22, Real Estate=3) and 44 sub-industries. `recovery.log`
  recorded `gics backfill: updated=109 mapping_rows=670
  unclassified_before=109 unclassified_after=0`.
- Relaunch: idempotent — no second backfill log line, no DB write.
- `--legacy` smoke: bundled `node.exe` spawned, Next UI loads.
