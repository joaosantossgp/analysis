# CVM Analytics v0.27.3

Patch release introducing significant performance improvements to the Model Mapping workspace, reducing initial load times by over 95%.

## Changed

- **Resolution caching and indexing:** Added a pre-scored candidate cache and pre-indexed lookups in `ModelResolver`, avoiding redundant scans across statement lines and aliases.
- **Redundant call elimination:** Reorganized the mapping engine to resolve target entries once instead of thrice during workspace initialization, reducing total resolver calls from 6,708 to under 100.
- **React Query optimization:** Fixed a duplicate initial page request in the `CompanyModelMappingPage` UI by seeding the Query Client cache when transitioning from default to active preset IDs.
- **Frontend lookups:** Replaced client-side array search lookups (`.find()`) in rendering paths with memoized `Map` lookups, and bypassed redundant client-side formula evaluation for unmodified workspaces.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
- `pytest`
- `run_benchmark.py` mapping workspace validation

- Preserves full backward compatibility with SQLite, user override settings, and excel mapping validations.
