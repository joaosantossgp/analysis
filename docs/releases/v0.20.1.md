# CVMAnalytics v0.20.1 - Company Universe Entry Point

`v0.20.1` is a hotfix for `v0.20.0`. It makes the company-universe downloader
discoverable for existing installs that already have local CVM data.

## Summary

- Added a permanent `Company universe` page under the Database module.
- Added a Database sub-navigation tab for `Company universe`.
- Added a visible `Company universe downloader` card on the `Atualizar Base`
  page.
- Added a command-palette route for `Company universe`.
- Reused the first-run setup/download UI for the manual page so Top 100,
  Top 200, Top 500, and All B3 companies behave consistently.
- Replaced the misleading `Settings > Data` copy with
  `Database > Company universe`.

## Why

`v0.20.0` only opened onboarding for fresh installs with no setup state and an
empty local database. Existing users with data were correctly skipped, but they
had no obvious way to run the new company-universe downloader later.
