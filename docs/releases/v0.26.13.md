# CVM Analytics v0.26.13

Hotfix release for Plant Parcels startup on large local CCEE caches.

## Fixed

- Fixed Plant Parcels appearing to load indefinitely when the local hourly CCEE cache is very large.
- Replaced the exact `COUNT(*)` over `ccee_plant_parcel_hourly` with a fast row-presence/count estimate for source status cards.
- Let the Plant Parcels catalog render even if the source-status panel is still loading or fails.

## Changed

- Bumped app version to `0.26.13` in `desktop/__version__.py` and synced the desktop web mock bridge.
