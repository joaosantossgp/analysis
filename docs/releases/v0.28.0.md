# CVM Analytics v0.28.0

Minor release introducing the local-first ANEEL electricity distribution module with full KPI ingestion, desktop bridge, and distributor explorer UI.

## Added

- **ANEEL Electricity Distribution Module:** Full local-first offline-only distribution analytics module supporting distributor and economic-group modes.
- **Distributor Explorer UI:** New interactive distributor explorer panel rendering:
  - Historical SVG charts for Market, Balance, Quality, Tariffs, Delinquency, and MMGD metrics.
  - Data table representation utilizing the same underlying aggregate records.
  - Comprehensive refresh states (loading, error, empty, running, success, failure) with real-time status.
- **ANEEL Data Ingestion & Cache Engine:** Multi-source ingestion pipelines with Polars parser schema validations, normalized CNPJ lookup with 14-digit padding, and single-flight refresh lock to prevent concurrent runs.
- **Distribution Diagnostics:** Process logging in `energy_source_refresh_log` with step duration tracking (download, parse, publish, SQLite lock-wait), row counts, schema-drift detection, and CPU/RSS memory usage.
- **Reliable Transactions:** Fact publishing uses bounded SQLite batch insertion transactions, and aggregate rebuilds run strictly after source publication to ensure reads leverage clean cache snapshots.

## Changed

- **Country KPIs UI Integration:** Integrated the new distributor Explorer with `CountryKpisPage` and the desktop bridge API mappings.

## Validation

- `npm --prefix apps/desktop-web run typecheck`
- `pytest tests/energy_kpi/test_distribution_bridge.py`
- `pytest tests/energy_kpi/test_distribution_ingest.py`
- Full test suite execution (`pytest tests -q` and `pytest apps/api/tests -q`).

## Notes

- Requires Polars and SQLite. Offline mode is fully supported.
