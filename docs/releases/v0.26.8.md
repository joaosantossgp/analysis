# CVM Analytics v0.26.8

Patch release for transient SQLite locks during Plant Parcels imports.

## Fixed

- Fixed manual CCEE hourly generation imports failing with `database is locked` while inserting source metadata or refresh logs.
- Added retry handling around Plant Parcels refresh writes, including running-log creation, data upsert, and final log update.
- Added a regression test that holds a real SQLite write lock and verifies manual import waits and completes.

## Changed

- Bumped app version to `0.26.8` in `desktop/__version__.py` and synced the desktop web mock bridge.
