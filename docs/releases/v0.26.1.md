# CVM Analytics v0.26.1

Patch release for the Plant Parcels / Energy Utilities indicator refresh path.

## Fixed

- Fixed ANEEL SIGA refresh when the current CSV is served as `cp1252` instead of UTF-8.
- Fixed ANEEL source date parsing so ISO dates such as `2026-06-01` do not get interpreted as day-first dates.
- Added explicit source refresh diagnostics for plant/plant-parcel sources: requested period, source URL, downloaded bytes, source rows, parsed rows, normalized rows, inserted rows, skipped rows, warning/error, and detected encoding.
- Added zero-row warning handling so refreshes that import no rows are not shown as silent `missing` cache states.
- Added CCEE blocked/HTML response detection so HTTP 403 maintenance/block pages are reported as source failures.
- Made Plant Parcels catalog search accent-insensitive; `jupi` matches `Jupiá`.
- Updated Plant Parcels source cards to show refresh diagnostics and warning/error text.

- ANEEL SIGA refresh was verified locally with 25,253 parsed/imported source rows and `cp1252` encoding.
