# CVMAnalytics v0.18.2 — Analyst-Ready Excel Export Patch

CVMAnalytics `v0.18.2` is a targeted patch on top of `v0.18.1` that
redesigns the Excel export to follow the layout of a Wall Street Prep
financial-modeling reference workbook. The runtime, backend, database
schema, and bridge surface are unchanged.

## Summary

- **New "Financial Statement Model" main sheet:** consolidates all
  financial statements into a single analyst-facing worksheet, following
  the compact financial-modeling layout used by the reference workbook.
- **All statements in one sheet:** Income Statement (DRE), Balance Sheet
  (BPA Assets + BPP Liabilities & Equity), Cash Flow Statement (DFC),
  and KPIs / Ratios — all rendered in the main `Financial Statement Model`
  sheet.
- **Period layout:** quarters and annual columns interleaved
  (`1Q24, 2Q24, 3Q24, 4Q24, 2024, 1Q25, ...`), matching the reference
  workbook. Annual columns are subtly shaded.
- **Convention legend:** Input / Output / Calculation / Check / Note /
  Warning legend at the top of the sheet, with the color and font
  conventions used by the analyst community.
- **Company info block:** name, ticker, CVM code, CNPJ, GICS sector,
  CVM sector, latest fiscal year, latest quarter.
- **Checks section:** explicit `OK` / `WARNING` / `ERROR` text labels
  (not color-only) for Balance Sheet tie, period completeness, duplicate
  CD_CONTA detection, and critical line availability.
- **Source / Data Quality block:** generated-by, app version, export
  timestamp, periods exported, rows per statement, source attribution,
  unit note (CVM source = R$ mil; model displays R$ mm).
- **Scale conversion:** the model displays values in R$ mm (millions),
  computed by dividing the source R$ mil values by 1,000. Legacy sheets
  keep their original scale untouched.
- **Backward compatible:** all legacy sheets (CAPA, GERAL, KPIs, DRE,
  BPA, BPP, DFC, METADADOS) remain in the workbook for any tooling
  or downstream consumer that depends on them. The new model sheet is
  the first sheet of the workbook.

## Architecture Notes

- No Node/Next runtime reintroduced.
- No persistent user data paths changed.
- No database schema changes.
- No new Python or npm dependencies.
- Bridge surface (`export_company_excel`, `get_output_dir`) unchanged.
- Output filename convention unchanged
  (`{TICKER_OR_CVM}_{YYYYMMDD}.xlsx`).
- Packaged ZIP root remains updater-compatible: `CVMAnalytics.exe` and
  `_internal/`.

## Known Limitations

- DMPL: rendered only when source data is available; CVMAnalytics
  does not invent these rows when missing.
- Forecast columns: not generated. Only historical periods present in
  the local database are exported.
- LTM column: not computed in v0.18.2.
- Per-share rows, market prices, share counts: not populated (not in
  the CVM filings database).
- Statement-scoped exports (single-statement workbooks served by the
  legacy bridge path) still render the legacy single-sheet layout.
- Aptos Narrow font is declared as the primary font; Excel falls back
  gracefully to Calibri on systems where Aptos Narrow is not installed.
