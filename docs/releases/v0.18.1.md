# CVMAnalytics v0.18.1 — Terminal UI Patch

CVMAnalytics `v0.18.1` is a targeted patch on top of `v0.18.0`, hardening
the Terminal UI for reliability, performance, and accessibility without
introducing new features or touching backend/data paths.

## Summary

- **Terminal UI reliability:** standardized all terminal-pane state surfaces
  with a unified `StateBanner` component (loading/empty/error/browser-only
  variants) — replaces ad-hoc inline states that used color alone for
  signalling.
- **Performance — WebView2 smoothness:** memoized expensive derived
  computations (`buildKpiGrid`, `yearColumns`, sparkline value arrays) to
  eliminate redundant recalculations on re-renders; extracted `KpiTableRow`
  as `React.memo` to prevent cascade re-renders in large indicator tables.
- **Visual QA hardening:** removed Tailwind-specific focus-color overrides
  (`focus-visible:outline-zinc-500/70`, `focus-visible:outline-cyan-500/70`)
  that were defeating the global design-token focus ring
  (`--color-border-focus: #ff7a1a`). All interactive elements now resolve to
  the correct orange focus ring consistently.
- **Accessibility:** added `scope="col"` to all `<th>` elements in
  `CompaniesTable`, `CompanyDetailPage` KPI table, and `CompanyKpisPage`
  financial grid. Added glyph prefixes to Status chips (◌ Loading, ↻
  Refreshing, ! Error, ▲ Browser mode) so state is not communicated by
  color alone.

- No Node/Next runtime reintroduced.
- No persistent user data paths changed.
- No new npm/Python dependencies added.

  desktop releases).

## Known Limitations

- Vite emits `Generated an empty chunk: "vendor"` — React merges into the
  main index chunk; router (41 KB) and query (44 KB) split correctly. Harmless.
- Browser preview cannot render full bridge data without pywebview. Desktop
  manual inspection is the authoritative check.
